# Contributing to Reliquary

Thanks for helping. Bug reports, ideas and pull requests are welcome.

## Bug reports and ideas

Open an issue with one of the forms, or email
[support@libertyhillstudio.com](mailto:support@libertyhillstudio.com). For a bug, say which version
of Reliquary you have, what happened, and any error the game showed.

## Pull requests

- Run `tools/test.sh` before you send one.
- Reliquary never acts in the game for the player, and shares nothing the player hasn't chosen to
  share. Changes need to keep it that way.

Accepted changes are released with the next version.

By sending a pull request you agree that your contribution is licensed under the Apache License
2.0, as section 5 of the [License](LICENSE) says.
